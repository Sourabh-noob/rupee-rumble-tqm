# 📈 Rupee Rumble

**Rupee Rumble** is a high-stakes, real-time trading simulation game where teams manage a portfolio of ₹1,000. Unlike traditional quizzes, participants don't just answer questions—they bet their capital on their confidence. 

Survive the market volatility, protect your NAV (Net Asset Value), and climb the leaderboard in this competitive live event platform.

---

## 🚀 Key Features

### 🏦 Interactive Trading Terminal
*   **Capital Allocation:** Teams distribute their total balance across four possible answers (A, B, C, D).
*   **Risk Management:** Go "All-In" for maximum returns or "Spread Evenly" to hedge against uncertainty.
*   **Real-time Settlement:** Portfolios are updated instantly as soon as the market (timer) closes.

### 🎙️ Audio
*   **Procedural Audio:** Custom-synthesized sound engine for heartbeats, profit chimes, and market-close buzzers.

### 🛠️ Director Control Suite (Admin Panel)
*   **Live Orchestration:** Launch questions, control the global timer, and toggle leaderboard visibility from a unified dashboard.
*   **Question Bank Editor:** Hot-swappable questions synced directly to a Supabase backend.
*   **Session Management:** Full control over team registrations and session resets.

### 🛡️ Hardened Competition
*   **Anti-Cheat System:** Restricted copy/paste, right-click, and forbidden keyboard shortcuts to ensure integrity during the event.
*   **Rate Limiting:** Token-bucket protection on AI generation and database joins to prevent spam.

## 🛠️ Tech Stack

-   **Frontend:** React 19 + TypeScript + Vite
-   **Styling:** Tailwind CSS + Framer Motion (Animations)
-   **Backend:** Supabase (PostgreSQL + Real-time WebSockets)
-   **Data Vis:** Recharts (Equity curves and portfolio breakdown)

## 📦 Getting Started

### 1. Prerequisites
-   Node.js (v18+)
-   A Supabase Project
-   A Gemini API Key

### 2. Environment Setup
Create a `.env` file in the root directory:
```env
API_KEY=your_gemini_api_key
SUPABASE_URL=your_supabase_project_url
SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 3. Installation
```bash
npm install
npm run dev
```

### 4. Database Configuration
To enable the real-time sync and admin functionality, run the provided SQL schema in your **Supabase SQL Editor**. The schema can be found in the `AdminDashboard.tsx` component or generated by clicking the **"Copy SQL"** button in the **Setup** tab of the Admin panel.

## ☁️ Deployment

### Vercel (Recommended)
The project is optimized for Vercel. 
1. Push code to GitHub.
2. Import repository to Vercel.
3. Add environment variables in the Vercel Dashboard.
4. Deploy.

### Build Command
```bash
npm run build
```
The production assets will be generated in the `/dist` folder.
